      Review scope · 16 Nov 2026

      Use it with clear limits.

      A targeted source review supports a supervised trial. It is not a complete security audit or a malware certification. This companion uses only the upstream fact and writing checks. It does not run the upstream installer, dashboard, or autofill.

      Privacy · configure before use

      Upstream tailoring defaults to a hosted AI endpoint. Contact filtering is opt-in. Without a privacy configuration, pattern detection is off. This trial uses your Codex login and sends the inputs to OpenAI.

      Privacy code and limitations ↗

      Autofill · omitted from this trial

      Upstream excludes recognized Submit controls. Its code states that an allowed button can still submit through a custom script. The trial has no browser automation, employer request, or submission endpoint.

      Read the submit-guard limit ↗

      Installer · not run

      The installer downloads dependencies and a Chromium browser. The root package has no npm lockfile at the reviewed commit. Dependency vulnerabilities and every integration were not audited. This companion needs no npm installation.

      Inspect the package scripts ↗

      Useful safeguards · present in the source

      Upstream has fact checks, a local-only web bind, origin checks, and a PDF renderer with scripts and network access blocked. This trial returns text from a read-only Codex worker, checks it against the supplied resume, and renders text without executing model HTML.

      Inspect PDF isolation ↗

      AI detection · no bypass guarantee

      Plain writing can improve readability. It does not establish human authorship or guarantee a detector result. ATS readability is a separate issue. The trial does not upload your resume to a detector or claim a detector score.

      A detector vendor explains accuracy limits ↗

      Storage · private local trial

      The current source is in ignored cv.md. The last trial is stored in ignored resume-lab/.local/trial.json. Browser inputs are held in memory, not localStorage. Codex uses an ephemeral session; service-side handling follows your OpenAI account terms. Downloads remain on your device.
